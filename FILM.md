# Film — Working title

Shorts-first. Natural desk sessions on real cameras. **Full screenplays + shot lists below** — shoot from those, not from one-liners.

**Series:** Working title · **Deliver:** 30–90s vertical (crop 9:16 in edit from 16:9)  
**Rule:** No old portfolio projects on camera. Current desk / Hameli / tools / hire path only.

**Post order:** Questions → Tools → Decision → How to send.

**How to use this file today**
1. Lock the kit (both bodies on tripods + LA300Bi + Lark Max 2) — same positions for the whole sitting.
2. Shoot **BANK** shots first (shared B-roll).
3. Shoot each short’s **TODAY** shots in order; skip rows marked SCREEN LATER.
4. Record talk / VO the same sitting on Lark Max 2 (scripts are word-for-word — adjust one line if it isn’t true).
5. Screen-record later using the SCREEN LATER rows, then assemble with the cut order.

# SHORT 01 — Questions Before Frame One

**Runtime target:** 60s (ok 45–75)  
**Pillar:** Client-path  
**Logline:** Three questions that decide whether a build starts — said to camera, no archive tour.  
**Slugline:** INT. BRIEFING — DAY

### Screenplay

```
INT. DESK — DAY

AHMED at the desk. FX3 (50mm) on tripod to his eyes; FX30
covering profile. Lark Max 2 on. He looks at the A-cam lens
like the other person is across the wood.

                    AHMED
          Most projects don’t fail in the build.
          They fail before frame one — because
          nobody answered three questions.

He holds up one finger. (Or cut to B-roll under VO if you
prefer not to gesture.)

                    AHMED (CONT'D)
          One. What does done look like — in one
          sentence. Not a feature list. One sentence.

Beat.

                    AHMED (CONT'D)
          Two. What must not break. Brand, deadline,
          or budget. Pick the one that actually rules.

Beat.

                    AHMED (CONT'D)
          Three. Who decides when two options are
          both fine. If that person isn’t in the
          room, we don’t start.

                    AHMED (CONT'D)
          If they can’t answer these, we don’t start.
          Next short — what I actually open at this
          desk. hameli.io. hello@hameli.io.
```

# SHORT 04 — How to send me a project

**Runtime target:** 45s (ok 30–60)  
**Pillar:** Client-path  
**Logline:** What belongs in the first email — and what gets ignored.  
**Slugline:** INT. INBOX — DAY

### Screenplay

```
INT. DESK — DAY

Ahmed to A-cam (FX3 · 50mm). Lark Max 2 live. Phone on desk
optional for mail insert — sample email compose later.

                    AHMED
          If you want something built, don’t send me
          “need a website.” Send me three things.

Holds up fingers / cuts on inserts.

                    AHMED (CONT'D)
          One — the outcome. What should exist when
          we’re done. One sentence.

                    AHMED (CONT'D)
          Two — the constraint. Time, budget, or a
          hard brand rule. The one that actually binds.

                    AHMED (CONT'D)
          Three — the deadline, and who decides.
          If you can’t name the decision-maker, we
          can’t start.

                    AHMED (CONT'D)
          That’s the email. hello@hameli.io.
          Or start at hameli.io.
```
