## How a VO-led short is cut

1. Screen-record the demo / session (hide private windows).
2. Record VO (4–7 beats: what it is → what changed → takeaway → CTA to demo URL).
3. Drop **2–5** coverage shots (C1–C10) on cuts / breaths — not every second.
4. Export; crop vertical; post.

Talk-to-camera is **optional**, rare. Default is VO.

## Test run — Use this for that (how to cut the video)

Three layers. VO is the spine. Screen is most of the picture. Desk shots only on breaths.

**Runtime:** ~65s · **Deliver:** 9:16 (crop from 16:9) · **Page:** `/week`

```
VO (Lark)  +  screen of /week  +  2–3 desk shots
```

### 1. Record the VO first

Lark Max 2, quiet room, one take as if one person is across the desk. Clap once at the start. Keep the take even if a line is slightly off — recut later.

| Time | Line |
|------|------|
| 0:00–0:07 | Four tools this week. Use theirs. Or I can make you one. |
| 0:07–0:20 | Gemini 3.7 Flash — drop a screenshot, get a first page. If you want it to be yours, I can make you that. |
| 0:20–0:33 | A coding agent — describe a small app, let it draft. If you want it to match how you work, I can make you that. |
| 0:33–0:46 | Openmotion or isolate.video — screens into a short. If you want it to look like your product, I can make you that. |
| 0:46–0:56 | Don’t give any of them your passwords and walk away. They wander. |
| 0:56–0:65 | Links on hameli.io/week. hello@hameli.io if none of them fit. |

### 2. Screen-record `/week` (play the VO in your ear)

Browser: hameli.io/week or localhost `/week`. Hide bookmarks, other tabs, private windows. Record the **center** of the page (that’s what survives the 9:16 crop).

Scroll so the picture matches the line you’re hearing:

| VO beat | What’s on screen |
|---------|------------------|
| Open | Title: **Use this for that** |
| Gemini | SC. 01 — hold **Use this** |
| Coding agent | SC. 02 — hold **Use this** |
| Openmotion | SC. 03 — hold **Use this** |
| Passwords | SC. 04 — hold the headline |
| Close | END BRIEF + hameli.io/week |

One continuous scroll is enough. Don’t click source links on camera.

### 3. Film two or three shots (not a full bank)

Same sitting, kit already up:

| Shot | Cam / lens | Picture | Where it goes |
|------|------------|---------|---------------|
| C2 | 100mm | Hands on keys | Under the Gemini beat, 2s |
| C5 | FX3 · 50mm | Face on the screen, not talking | Breath before “passwords” |
| C6 | FX3 · 50mm | One glance to A-cam | Last line only |

Skip C1–C10 extras for this cut.

### 4. Assemble

Timeline, top to bottom:

1. **A1** Lark VO (full length — this sets the cut)
2. **V1** Screen record, slip so title hits “Four tools…”
3. **V2** Drop C2 / C5 / C6 on top for 1.5–2.5s each — never over a tool name
4. Captions: tool names only (Gemini, coding agent, Openmotion) — center-safe, above the IG/YT UI
5. Export 1080×1920, no music or bed only if it’s barely there
6. Post IG + YT Short · pin hameli.io/week

- [ ] C2, C5, C6
- [ ] Cut to VO

## Don’t

- Wait for “perfect” talk scripts before grabbing coverage
- Geo-local trend framing
- Show or name old portfolio projects
- Fill the short with face-talk and no product
- Rebuild the whole kit between every 8s take — set once, run the bank
