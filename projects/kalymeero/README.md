# Kalymeero

Kalymeero is the cooking content project under Hameli.

This folder is the source of truth for Kalymeero's content strategy, research, recipes, ideas, branding, analytics, and platform-specific publishing work.

## Structure

- `strategy/` — positioning, audience, goals, content pillars, experiments
- `research/` — topic, trend, audience, competitor, cultural, and factual research
- `recipes/` — recipe concepts, testing notes, ingredients, methods, and final versions
- `ideas/` — raw ideas and future content backlog
- `branding/` — identity, tone, visual direction, naming, and brand assets documentation
- `analytics/` — performance reviews, metrics notes, learnings, and decisions
- `platforms/youtube/` — YouTube-specific titles, scripts, descriptions, thumbnails, long-form and Shorts planning
- `platforms/tiktok/` — TikTok-specific hooks, edits, captions, trends, and publishing notes
- `platforms/instagram-reels/` — Instagram Reels-specific edits, captions, covers, and publishing notes

## Rule

Keep reusable project knowledge at the Kalymeero level. Only put something inside a platform folder when it is genuinely specific to that platform.

Move local Mac material here only when it becomes useful or necessary to the ongoing source of truth.

## Related repository

The separate `hamz1188/kalymeero` repository can hold implementation/code or other project-specific technical work. This Hameli folder holds the wider knowledge and content operating system.
